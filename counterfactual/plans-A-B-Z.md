## 2. 两个决定性洞察（这决定了三个方案的形状）

### 2.1 "IV 看起来很贵，所以卖它" —— 这是陷阱

| 指标 | 数值 | 说明 |
|---|---|---|
| 滚动 20 日已实现波动率 | **≈ 376%** | 含 8/19、8/20 两根跳空 `[精确算术]` |
| 滚动 60 日已实现波动率 | **≈ 219%** | 同上 |
| 假设的 30 天隐含波动率 | **≈ 85%** | `[假设]` |

**诚实的限定**：376% 被那根一次性跳空严重放大，**不能**直接当作未来已实现波动率的预测——那根跳空不会重演。所以真正的论点不是"隐含比已实现便宜"这种粗糙比较，而是下面三条：

1. **波动率聚集（GARCH 持续性）**：极端跳空之后数周，已实现波动率仍会显著高于事件前基线。
2. **跳空风险并未消失，只是换了日期**：完整疗效数据（HR）尚未公布、监管路径尚未走完、OS 数据尚未成熟。**每一个都是新的二元事件。**
3. **高斯型隐含波动率不给跳空定价**。卖期权是做空一个**跳跃过程**，而 85% 的 IV 只补偿了扩散过程。

> **结论：此刻卖出波动率，是在一个跳空刚刚发生两次、且还有更多跳空排队的标的上，
> 用扩散过程的价格去卖跳跃过程的风险。**

### 2.2 镜像错误警告：现在转空，是同一个错误换方向

原罪的结构是：**行情已经发生 → 我才动手**。

如果我今天因为"跌了 23.55%"去买看跌期权、做空、或买入熊市价差，我做的是**结构完全相同的事**：
追一个**已经发生**的行情，并为刚被抬高的隐含波动率付钱。

| | 8/19 的错误 | 8/20 可能犯的错误 |
|---|---|---|
| 触发 | 已发生的 +177% | 已发生的 -23.55% |
| 动作 | 追多 | 追空 |
| 支付 | 被抬高的看涨 IV | 被抬高的看跌 IV |
| 本质 | **对已实现行情的反应** | **对已实现行情的反应** |

**IT-5 对两者一视同仁：催化剂已经落地 → 不许交易该标的的方向。**

## 3. Plan A：进攻

> **只有当 §0.3 第 1 项（下一个催化剂的确切日期）被确认后，本方案才成立。查不到 = 不许下单。**

**论点（必须写成 3 句以内）**：8/19 只披露了"达到主要终点"，**未披露风险比（HR）**。
完整疗效数据在未来某个医学会议／监管节点公布时，市场才第一次能够**为幅度定价**。
我要用**有限成本**买下这个"幅度被定价"的时刻。

### 3.1 主结构：看涨垂直价差（2 腿，借记）

| 项目 | 数值 `[假设IV=72%, 90天]` |
|---|---|
| 结构 | **买入 C@2.20 + 卖出 C@2.90** |
| 到期 | **必须在确认的催化剂日期之后**（示例用 90 天） |
| 净支出 | **0.1796** = 现价的 **8.5%** |
| 最大收益 | 0.5204 |
| **盈亏比** | **2.90 : 1** |
| 保本点 | 2.3796（**+12.4%**） |
| 最大亏损 | **= 净支出，有限** |
| 下注规模 | **≤ 1% 净值**（IT-13/14） |
| 净值影响 | 最坏 **-1.00%** · 最好 **+2.90%** |

**为什么是垂直价差而不是裸买看涨**：卖出 2.90 腿把 vega 大幅对冲掉。裸买看涨在"IV 仍高 + 短期无催化剂"下会被 theta 和 vega 双杀——那正是 8/19 期权腿亏 96% 的机制。垂直价差把这个机制关掉了。

**为什么短腿设在 2.90**：它**高于我的成本基础 2.77**。若这笔交易全额获胜，我不仅赚钱，而且是在**打平之上**结束。

### 3.2 备选：反向铁鹰（4 腿，方向中性）

适用情形：**确信会有大波动，但不确定方向**（例如完整数据可能极好也可能平庸）。

| 项目 | 数值 `[假设IV=72%, 90天]` |
|---|---|
| 结构 | 买 C@2.20 / 卖 C@2.90 **＋** 买 P@2.00 / 卖 P@1.40 |
| 净支出 | 0.3717 = 现价的 **17.5%** |
| 上行最大收益 | 0.3283 · 下行最大收益 0.2283 |
| 双向保本 | 上 **+21.4%** / 下 **-23.1%** |
| 净值影响 | 最坏 **-1.00%** · 最好 **+0.88%** |

**诚实的缺点**：盈亏比只有 **0.88:1**，远差于垂直价差的 2.90:1——因为此刻 IV 偏高，双向买入太贵，而且 4 腿的买卖价差会再吃掉一块。**IV 百分位 > 80 时（IT-11），此结构不予授权。**

### 3.3 Plan A 的纪律

| 项目 | 规则 |
|---|---|
| 前置条件 | 催化剂日期已确认；IV 百分位 < 80；短空头持仓已回落（H1 已出清） |
| 失效条件 | 已确认发生增发（H5）；或催化剂日期被推迟到到期日之后 |
| 时间止损 | 催化剂公布后 **2 个交易日内**平仓，无论盈亏 |
| 严禁 | 加仓、展期、把短腿买回变成裸多 |

## 4. Plan B：稳重

> 适用情形：**我仍持有股票**，不想认赔离场，但必须**停止流血**并利用被抬高的上行 IV。

**论点**：大涨之后，**上行看涨期权是整条波动率曲面上最被抬高的部分**（追涨需求 + 正偏斜）。
把这个最贵的部分**卖出**，用来**买入下行保护**——这是唯一一个方向正确的相对价值交易：
**卖出被高估的凸性，买入被需要的保护。**

### 4.1 主结构：领口（2 腿 + 持股）

| 项目 | 数值 `[假设IV=72%, 90天]` |
|---|---|
| 结构 | **持股 + 买入 P@1.90 + 卖出 C@2.90** |
| 买看跌成本 | 0.1807 |
| 卖看涨收入 | 0.0957 |
| **净支出** | **+0.0850** = 现价的 **4.01%** |
| 下限 1.90 | 自当前 **-14.29%** ／ 对成本基础 **-34.48%** |
| 上限 2.90 | 自当前 **+32.93%** ／ 对成本基础 **+1.62%** ← **高于打平** |

### 4.2 净值层面（假设股票仓位 = 净值 2%）

| 情景 | 股票端 | 净值影响 |
|---|---|---|
| 触及下限 1.90 | -14.29% | **-0.29%** |
| 触及上限 2.90 | +32.93% | **+0.66%** |
| **无保护**跌回事件前 1.00 | -52.78% | **-1.06%** |
| **领口消除的尾部** | — | **0.85% 净值** |

### 4.3 Plan B 的生死线

> **卖出的看涨期权行权价必须高于成本基础 2.77。**

| 卖出腿 | 结果 | 判定 |
|---|---|---|
| C@2.90（> 2.77） | 上限对应 **+1.62%** vs 成本基础 | ✅ **允许** |
| C@2.20（< 2.77） | **永久锁定 -14.31%**，下跌仍全额承担 | ❌ **严禁（= ✗5）** |

这条线是 Plan B 与"最糟策略第 5 名"之间**唯一**的区别，两者外形几乎一样。**只差一个行权价的位置。**

| 项目 | 规则 |
|---|---|
| 失效条件 | 已确认增发 → 领口改为直接减仓 |
| 严禁 | 卖出腿低于 2.77；为了"零成本"把看跌下限压到 1.40 以下（那等于放弃保护） |

## 5. Plan Z：防守

> 适用情形：**生存优先**。我承认自己在 8/19 的判断不可信，因此把"判断"从仓位里移除，
> 只保留**有限成本的凸性**。

**论点**：我现在持有的是一个**凹性**头寸（上行有限、下行 -52.78% 才回到起点）。
Plan Z 的全部目的是**把它换回凸性**——这正是原则 1 的字面执行。

### 5.1 主结构：股票替换（1 腿）

| 项目 | 数值 `[假设IV=65%, 180天]` |
|---|---|
| 结构 | **卖出全部股票 + 买入 180 天 C@2.20** |
| 卖股回收现金 | 2.1177 |
| 买入看涨成本 | **0.3665** = 回收现金的 **17.3%** |
| **释放资本** | **1.7512 = 82.7%** |
| 下行风险 | 从 **-2.1177（全额）** 降为 **-0.3665（有限）** |
| **削减的尾部** | **82.7% 的下行被永久消除** |
| 保本点 | 2.5665（**+21.2%**） |
| 净值影响（原 2% 仓位） | 最坏 **-0.35%** · 上行保留 |

**这个结构同时做到四件事**：
1. 下行从"无底"变成"已付的权利金"——**跌回事件前不再伤我**；
2. **保留全部上行**（完整数据若极好，我仍在场）；
3. **释放 82.7% 的资本**——凸性投资的核心是"成本可控"，释放的现金就是可控性；
4. 把仓位规模自动压回 IT-13 的授权范围内。

### 6.1 选哪一个：决策树

| 判断 | 结论 |
|---|---|
| 8/19 之前**没有**书面论点？ | → **Plan Z**，今天执行（IT-18）。不必再往下看。 |
| 有书面论点，且**已确认**下一个催化剂日期？ | → **Plan A**，规模 ≤1% 净值 |

## 7. 收尾：这三个方案真正的共同点

| | 8/19 我做的 | Plan A / B / Z 都做的 |
|---|---|---|
| 凸性方向 | **卖出**（买了已兑现的凸性） | **买入或掩护**，绝不裸卖 |
| 最大亏损 | 未计算 | **事前精确已知且有限** |
| 规模依据 | 情绪 | **规则**（≤1–2% 净值） |
| 出场 | 无 | **失效条件 + 时间止损，事前写下** |
| 催化剂 | **已落地** | **尚未落地**（A），或不依赖催化剂（B、Z） |

> **8/19 的错误不是"看多 MRNA"，而是"在事件落地后、用未定规模、买入已兑现的凸性"。**
> Plan A / B / Z 三者都可以看多 MRNA。它们与 8/19 的区别，
> **不在方向，而在凸性的方向、亏损的有界性、和规模的来源。**

**最后一次强调最糟的那一笔：**

> **裸卖看跌 / 卖出宽跨式。**
> 收 3.47% 的权利金，去承担 33%–52% 的单次亏损，赢面 77%，输一次抵 9.5 次赢，
> 而这个标的 36 小时内刚刚跳空两次、且完整数据尚未公布。
>
> **它看起来像"稳健收租"，实际上是本仓库全部哲学的精确反面。**
